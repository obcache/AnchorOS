# ANCHOR_Bootstrap

## v0.5
- BIOS-level loader that reads the manifest, validates the complete required
  set, and invokes initialization in one enforced order.
- Registers the manifest CLI before initialization but does not activate
  governed runtime behavior until explicit `| anchor init` authorization.
- Verifies each capsule's filename, version, role, expected caller, expected
  sequence, and SHA-256 digest before accepting it.
- Rejects duplicate sequence positions, missing capsules, unexpected required
  capsules, hash mismatches, and handshake metadata mismatches.
- On any failure, reports the failing capsule and reason, clears staged init
  state, and halts without partial activation.

## Initialization Transaction
1. Stage all required capsules in observation mode.
2. Verify the complete set and all integrity metadata.
3. Read capsules only in the required load order.
4. Confirm readiness and await explicit operator authorization.
5. On `| anchor init`, activate the verified set atomically and set
   `system_state.running = true`.
